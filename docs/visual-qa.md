# Visual QA

Reviewed in Phase 2 on the Redmi `garnet` (HyperOS, 1220 x 2712, density 2.75), plus the
Roborazzi goldens in `app/src/test/screenshots`.

## What was checked

- Screens: Home, Apps, Reels, Web.
- Goldens: soft card, pill toggle, segmented pills, status ring, mini bar chart.
- Reports: 9 golden screenshots and 61 unit tests green, lint reports 0 issues.
- Tokens: no hardcoded colors, radii, or shadows outside `design/`.
- Touch targets: 48 dp minimum on every interactive element.
- TalkBack: every toggle announces its role and label, charts carry a summary, and the dock
  announces the selected tab.

## Findings and fixes

| Finding | Fix |
|---|---|
| The secondary pill was nearly invisible on white cards (`SurfaceMuted` on `Surface`). | The secondary style uses `CanvasRaised`, which reads as a control without a border. |
| Uppercase tracked overlines read like template badges. | Sentence case with light tracking, per the unslop adaptation in the plan. |
| The variable font ignored every weight; all text rendered regular. | Five static Plus Jakarta weights are bundled and mapped to 400 to 800. |
| The Pip idle float was motion without meaning. | Removed. Illustration is static and motion is reserved for state changes. |
| The Home subtitle was generic. | It states the real number of active protections and updates as the switches change. |
| The date overline shouted. | `Sunday, 15 November`, not `SUNDAY, 15 NOVEMBER`. |
| Zero-value chart bars looked like data. | They render as a 4 dp baseline tick, visibly different from a real bar. |
| Gaps between cards measured 8 to 27 dp because an 8 dp shadow filled the 14 dp spacers, and gradient cards faded into the canvas so their bottom edge disappeared. | Shadow drops to 4 dp, gradients end on their own tint instead of the canvas, and every card gap is 16 dp. Measured clean canvas between cards is now 8 to 10 dp, evenly. |
| The mascot added a character to maintain and a card to explain it. | Removed. Personality comes from type, color, and object illustrations. |
| Package names and "Detected natively" exposed internals. | Removed. Rows show the app or platform name only. |
| Filler overlines above every page title. | Removed from Apps, Reels, and Web. Home keeps the date, which is real information. |
| The section color lived inside the hero card, so the page itself was flat and the card had to carry both identity and content. | The wash is now the page background: it falls in on tab change, fades to the canvas by 78 percent of the height, and every card is plain white. |
| Outline icons at a 1.75 stroke read thin against the pastel circles. | Heroicons solid at 24 dp, generated by `tools/heroicons_to_vector.py`. One filled shape per idea, no stroke tuning. |
| The default Navigation crossfade lasted long enough to ghost two screens at once. | Tabs are a pager now: the page follows the finger, the dock scrub jumps pages, and the wash falls in when a new page becomes current. |
| Toggles and the sensitivity control read as flat stickers on the page. | Both sit in a shallow recess: a 6 percent warm inner shade, a top inner shadow, and a raised white thumb or pill. The segmented control is draggable as well as tappable. |
| Every switch stayed sage green, even on the lilac and sky tabs. | Controls read the tab accent from a composition local: switch on-state, checks, day chips, selected segment label, and the active dock icon all follow the section. Neutral chrome stays neutral so color still means "on". |
| The tab bar and the sensitivity control were two different components with two different drag behaviors. | Both are one `SegmentedTrack`: one sliding pill, one drag gesture, one inset treatment. |

## Known gaps, by phase

- There is no mascot. Object illustrations are still placeholders until the Phase 9 art pass.
- Home and feature numbers are demo values until the services feed counters in Phases 4 and 6.
- Toggles hold local state only in this phase; persistence arrives with the ViewModels.
- Bar and ring values animate from zero on first composition; reduced motion support lands in Phase 3.
- Light theme only; the warm dark theme is a v1.1 item.

## Measuring rhythm

`tools/measure_rhythm.py <screenshot> [x]` walks one column and prints card runs and clean-canvas
gaps in dp. It is how the uneven spacing above was found and confirmed fixed, rather than judged by eye.

## Deliberate choices that a reviewer may question

- Bold display type (700) is kept against the general preference for 400 to 600. The direction in
  plan section 5.1 depends on it, and the deviation is recorded in 5.11.
- Cards float with a warm diffuse shadow instead of a hairline border. This is the one place the
  app spends elevation, and it is what makes the surface read as tactile rather than flat.
- The floating dock scrolls content underneath it. Content still ends above the dock when scrolled
  to the bottom, because the scaffold reserves the dock height.
